# 🛣️ Highway Gourmet Road

> 
> **전국 휴게소 맛집 및 여정 정보 큐레이션 시스템** > 고속도로 여행 중 최적의 휴게소와 맛집 메뉴를 쉽고 빠르게 추천받는 Flask 기반 웹 서비스입니다. 
> 
> 

## 📌 프로젝트 개요

* 
**프로젝트 기간:** 2025.12.09 ~ 2025.12.22 (약 2주) 


* 
**목표:** 단순 경로 안내를 넘어, 휴게소별 대표 메뉴 및 시설 정보를 통합 제공하여 사용자 편의성을 극대화한 경량 웹 서비스 구현 



## 🛠 기술 스택

* 
**Backend:** Python Flask 


* 
**Frontend:** HTML5, JavaScript, Tailwind CSS (Jinja2 Template Engine) 


* 
**Database:** MariaDB 


* 
**AI & API:** Google Gemini API (AI 메뉴 추천), Kakao Maps API (경로 안내 및 마커) 



## ✨ 주요 기능

1. 
**실시간 경로 탐색:** 출발지와 목적지를 입력하면 Kakao Maps API를 통해 최적 경로와 예상 소요 시간 및 거리를 제공합니다. 


2. 
**휴게소 큐레이션:** * **근접성 필터링:** 경로 반경 1.5km 이내의 휴게소만 노출합니다. 


* 
**방향 체크:** 상행/하행 방향을 판별하여 진행 방향에 맞는 휴게소를 정렬합니다. 




3. 
**AI 메뉴 추천:** Google Gemini API를 연동하여 각 휴게소의 대표 메뉴와 특징을 AI가 직접 요약 설명해 줍니다. 


4. 
**상세 정보 제공:** 휴게소별 편의시설(주유소, 전기차 충전소, 약국, 수유실 등) 정보와 카카오맵 위치보기 링크를 연동합니다. 



## 🏗 시스템 아키텍처

1. 
**사용자 접속:** 브라우저를 통해 Flask 서버에 접속 (index.html 렌더링) 


2. 
**데이터 처리:** `app.py`에서 Kakao API와 통신하여 좌표를 변환하고, `db.py`를 통해 MariaDB에서 휴게소 정보를 조회합니다. 


3. 
**시각화:** `main.js`에서 경로 Polyline을 생성하고 필터링된 휴게소를 마커와 카드 형태로 시각화합니다.
